# GTU Physics 3110018 Hall effect calculator

Hall effect came in 6 of 9 official GTU Physics 3110018 (Group 2) papers in GTU Hero's count (Summer 2022 to Summer 2026), in the Measurements unit. Ye page formulas se answer nikaalta hai so you can check your own working.

Live page: https://princeadvant.github.io/gtu-hall-effect-calculator/

## Formulas

- VH = B I / (n q t)
- RH = 1 / (n q)
- n = B I / (VH q t)

## Test

`node test.js` checks the formulas against hand-worked values and prints `All checks passed`.

## Tips

- t is thickness along B, in metres.
- State the sign of RH: negative for electrons, positive for holes.
